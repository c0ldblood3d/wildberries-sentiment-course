# Model Card: Wildberries review sentiment

## Назначение

Классификация текста отзыва на `negative`, `neutral` или `positive` для демонстрации и исследовательского анализа обратной связи.

## Метод

Три сравнимых эксперимента используют word TF-IDF с Logistic Regression (`C=1`, `C=3`) и word+character TF-IDF с LinearSVC. Поля текста, достоинств и недостатков объединяются. Итоговая модель выбирается по validation macro F1 и обучается повторно на train+validation.

## Оценка

Основная метрика — macro F1. На validation лучшая конфигурация получила macro F1 0.6536. На отложенном test: macro F1 0.6276, accuracy 0.8194, weighted F1 0.8247. По классам F1: negative 0.6897, neutral 0.2772, positive 0.9159. Сводная таблица validation экспериментов находится в `reports/experiments.csv`; test метрики и оценки по классам — `reports/test_report.json`. Test разделён по товарам и не используется для выбора гиперпараметров.

## Ограничения и риски

Целевая тональность выведена из рейтинга, поэтому она может расходиться с содержанием текста. Данные несбалансированы: положительный класс преобладает. Нейтральность неоднозначна. Модель — линейная bag-of-ngrams модель и не понимает длинный контекст, сарказм и факты о товаре. Не использовать для автоматических решений о продавцах, покупателях или модерации без проверки человеком.
