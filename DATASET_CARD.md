# Dataset Card: отзывы Wildberries

## Источник и лицензия

Исходный файл `filtered.csv` предоставлен пользователем для учебной работы; исходное происхождение и лицензия в задании не указаны. До публичного размещения следует проверить право на распространение исходных отзывов. Данные не коммитятся в этот Git-проект.

Исходный SHA-256: `eca8620637127841f3f8cc108ffbee839e18d0584de79ed5eef74c8e020b9cf6`. Версия v1: 27 248 строк, SHA-256 `4d6b3e22b29373b1bd49bdc5c792ba620d68ff8c6ef21ddb24cd2d9f46842ef4`. Версия v2: 27 248 строк, SHA-256 `76ea7497edbf65a48359b77aea27cc30f3b99e76a9eb6e786b67aa43225b2672`.

## Состав

Ожидаемые поля: `review_id`, `product_id`, категория, `rating` (1–5), `text`, `pros`, `cons`, дата. Исходная копия содержит 27 248 записей и 7 086 товаров. Пропущенные текстовые поля заменяются пустой строкой.

## Метки и preprocessing

1–2 звезды → `negative`, 3 → `neutral`, 4–5 → `positive`. Конкатенируются `text`, `pros`, `cons`, нормализуются повторные пробелы, пустые тексты удаляются. v1 сохраняет исходный регистр; v2 приводит текст к нижнему регистру и удаляет дубликаты по паре `review_text + rating`. `data/versions/manifest.json` содержит SHA-256 и число строк каждой версии.

## Разбиение

Версия v2 детерминированно делится GroupShuffleSplit (seed 42) примерно на 70% train, 10% validation и 20% test. Группировка по `product_id` исключает один товар из более чем одной выборки. Параметры выбираются только по validation; test открывается для итоговой оценки.

## Ограничения

Распределение классов несбалансировано, а рейтинг является шумной заменой ручной разметки. Точные дубликаты удаляются только в v2. Одна случайная групповая разбивка не измеряет полностью устойчивость к временным сдвигам или новым категориям. Контрольные суммы и версии воспроизводятся скриптом подготовки.
